Privacy Policy

Last updated: November 14, 2026

1. Who is responsible

The operator of the AnimationStudio YouTube channel and TikTok account, based in Germany. Contact: whatif.claude@gmx.de.

2. What this tool is

AnimationStudio Uploader ("the tool") is a private, self-hosted tool. It is used only by its operator to publish the operator's own videos to the operator's own YouTube channel and TikTok account, and to read statistics about those videos. The tool is not offered to other people, and no other user can connect an account.

3. Data the tool accesses

YouTube (Google), through the YouTube API Services, with the operator's consent:

  • youtube.upload: upload videos to the operator's channel
  • youtube.readonly: read the channel's name, video list and video details
  • yt-analytics.readonly: read performance statistics of the operator's videos (for example views, watch time, average view duration, subscribers gained)

TikTok, through TikTok for Developers, with the operator's consent:

  • user.info.basic: read the account's display name and avatar
  • video.upload and video.publish: upload and publish the operator's videos
  • video.list: read the operator's videos and their public statistics (for example views, likes, comments, shares)

The tool does not access data of viewers or other users, and it does not read private messages.

4. How the data is used

  • to upload videos after the operator has approved each one;
  • to create private performance reports for the operator, which help decide on future video topics.

Aggregated statistics of the operator's own videos may be processed by an AI language model provider (accessed through OpenRouter) solely to write these reports for the operator. The data is not sold, not used for advertising, and not used by the operator to develop or train AI models.

5. Storage and security

Access tokens and statistics are stored on a private server located in the European Union. Token files can only be read by the tool's own system user. Access to the server is restricted to key-based login. Statistics are kept as long as they are useful for the operator's reports and can be deleted at any time.

6. Sharing

Data is not shared with third parties, except the AI language model processing described in section 4 and the platforms themselves (YouTube, TikTok) when videos are uploaded.

7. Google API Services User Data Policy

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. By using the YouTube features, the operator is bound by the YouTube Terms of Service; Google's handling of data is described in the Google Privacy Policy.

8. Revoking access and deleting data

  • Google/YouTube access can be revoked at any time at Google security settings.
  • TikTok access can be revoked in the TikTok app under Settings and privacy → Security → Apps and permissions (wording may differ by app version).
  • After access is revoked, the stored tokens are deleted. Stored statistics are deleted on request to whatif.claude@gmx.de within 30 days.

9. This website

This website is hosted by GitHub Pages (GitHub, Inc.). It uses no cookies, no analytics and no tracking. GitHub may log technical data such as IP addresses to deliver the site securely; see the GitHub Privacy Statement.

10. Your rights

Under the GDPR you have the right to access, rectification, erasure, restriction of processing, data portability and objection, and the right to lodge a complaint with a data protection supervisory authority. Contact: whatif.claude@gmx.de.
